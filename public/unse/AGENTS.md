# 운세 정적 사이트 규칙

- 이 폴더는 React/TypeScript가 아닌 바닐라 ES 모듈 정적 사이트다. 관련 소스와 테스트만 좁혀 읽는다.
- 달력·간지·천문·명반·대운 등 계산은 엔진이 결정한다. AI에는 계산된 근거만 전달하고 재계산시키지 않는다.
- 명확한 오류와 관련 회귀 테스트 없이는 기존 계산식·기준을 바꾸지 않는다. 한 사례에 맞추어 후보·임계값을 조정하지 않는다.
- `app/fortune-ai/route.ts`의 요청 크기 제한과 기존 Claude 단일 제공자 정책을 지킨다. 원문 명반·로그·전체 데이터를 그대로 보내지 말고, 질문에 필요한 요약과 근거만 전달한다.
- AI 출력은 간결하고 구조화하며 길이를 제한한다. 같은 명반/질문의 재호출, 프롬프트·컨텍스트 중복을 피한다.
- 변경 범위에 따라 `npm run test:unse`를 먼저 실행하고, Next 연동 변경이 있으면 `npm run build`도 실행한다.
