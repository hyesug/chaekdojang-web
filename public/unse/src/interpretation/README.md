# 15체계 근거 해석 엔진

이 폴더는 출생정보로 계산된 결과를 현실 후보로 번역한다. 사례의 직업·결혼·질병·자녀 정보는 이 엔진의 입력이 아니다.

## 역할 분리

| 질문 | 직접 근거 체계 | 보조 체계 |
| --- | --- | --- |
| 직업 | 사주·자미·서양·베딕·홍국·육임 | 나머지 기질 체계 |
| 관계 | 사주·자미·서양·베딕·숙요 | 나머지 기질 체계 |
| 재물 | 사주·자미·서양·베딕·홍국 | 나머지 기질 체계 |
| 건강 | 사주·자미·서양·베딕 | 나머지 기질 체계 |
| 학업 | 사주·서양·베딕 | 나머지 기질 체계 |

직접 근거 체계는 해당 전통 안에 십신·궁위·하우스·다샤처럼 질문 분야를 따로 보는 장치가 있어야 한다. 보조 체계는 결론을 늘리거나 표본상 맞았다는 이유만으로 직접 근거가 되지 않는다.

## 결과 규칙

- 후보는 두 개 이상 직접 체계의 근거가 있어야 한다.
- 상반된 후보가 모두 지지되면 `conflicted`를 반환한다.
- 구체 사건(결혼 여부, 이혼, 자녀 수, 수술, 직업명)은 원국만으로 단정하지 않는다.
- 시기는 `validation/`의 월별 백테스트 결과로만 평가한다.
- 점수는 확률이 아니며 체계 안에서의 상대 순위다.

## 규칙 추가 절차

1. 새 규칙은 어느 체계의 어떤 계산값을 쓰는지 명시한다.
2. 기존 사례의 사실을 조건으로 사용하지 않는다.
3. 서로 다른 생활권·연령대의 독립 사례에서 재현되는지 기록한다.
4. 최소 30~50 사건 전에는 가중치를 자동 최적화하지 않는다.
5. 실패 사례 하나만으로 규칙을 추가·수정하지 않는다.
