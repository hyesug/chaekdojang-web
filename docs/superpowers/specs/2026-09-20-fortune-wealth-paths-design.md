# 재물 경로·횡재 분석 설계

## 목표

"재물운이 좋다/나쁘다"를 없앤다. 같은 '큰돈'이라도 월급이 오른 것, 계약이
터진 것, 상속을 받은 것, 복권에 당첨된 것은 **전혀 다른 사건이고 명반에서도
다른 자리가 켜진다.** 그 구분을 계산으로 만든다.

답할 수 있어야 하는 질문:

- 나는 월급으로 부자가 되는가 / 사업으로 되는가 / 투자로 되는가
- 배우자·가족 자산의 영향이 큰가
- 상금·지원금처럼 받는 돈이 있는가
- 예상하지 못한 목돈이 들어오는가
- 복권·추첨형 횡재 신호가 실제로 강한가
- 평생 중 언제 돈의 규모가 가장 커지는가

---

## 1. 새로 만든 계산

### 고전 서양점성술 (`hires/classical.js`)

기존 점성술 모듈은 현대식으로만 읽었다. 재물을 갈라 보려면 고전 장치가 필요하다.

| 항목 | 내용 |
|---|---|
| 섹트 | 태양이 지평선 위(7~12H)면 낮 차트. 섹트 길성·흉성이 여기서 갈린다 |
| 에센셜 디그니티 | 도미사일·엑절테이션·트리플리시티·텀·페이스·디트리먼트·폴 + 점수 |
| 액시덴털 컨디션 | 앵귤러/석시던트/케이던트 · 카지미 · 조합 · 태양광 아래 · 역행 · 속도 · 섹트 |
| 아라빅 로트 | 포춘 · 스피릿 · 에로스 · 네세시티 · 베이시스 · 서브스턴스 |
| 재물 하우스 | 2·5·8·10·11의 커스프·주인·주인의 자리와 상태·길흉성 |

**로트는 자리만 보지 않는다.** 로트의 주인이 어느 자리에 있고 어떤 상태인지를
함께 돌려준다 — 고전은 로트 자체보다 그 주인의 상태를 더 무겁게 보기 때문이다.

### 조디악 릴리징 (`hires/zr.js`)

발렌스의 헬레니즘 시기법. 포춘·스피릿이 놓인 별자리에서 출발해 별자리마다
정해진 햇수씩 돌아간다.

- **스피릿 기준** — 뜻·직업·명성이 언제 올라오는가
- **포춘 기준** — 몸·물질·환경이 언제 달라지는가

1단계(해)·2단계(달)까지만 만든다. **3단계 아래는 만들지 않는다** — 구현마다
값이 갈리고 검증할 길이 없어서, 없는 정밀도를 만들지 않는다.

### 재물 경로 엔진 (`hires/wealth.js`)

네 체계를 각각 읽어 일곱 경로로 합산한다.

```
노동형 · 전문성형 · 사업형 · 투자형 · 관계형 · 횡재형 (· 혼합형)
```

| 체계 | 무엇을 읽는가 |
|---|---|
| 사주 | 정재(꾸준한 돈)/편재(들고 나는 돈), 식상생재, 재생관, 재고(辰戌丑未), 비겁 과다 |
| 자미두수 | 재백·관록·복덕궁의 주성, 화록·화기, 녹존, 살성 |
| 베딕 | 2·5·8·11궁주의 자리, D2 호라, 다나/라자 요가, 라후의 자리, 목성 상태 |
| 고전 서양 | 포춘이 놓인 하우스와 그 주인, 2·5·8·10·11 주인의 디그니티, 섹트 길성 |

## 2. 유파 고지 (이번에 새로 고른 기준)

| 계산 | 고른 기준 | 갈리는 다른 기준 |
|---|---|---|
| 지배성 | **전통 지배성만** (천왕·해왕·명왕 없음) | 현대 지배성 |
| 트리플리시티 | **도로테우스** (낮·밤·협동) | 프톨레마이오스 |
| 텀(바운드) | **이집트 텀** | 프톨레마이오스 텀 |
| 페이스 | 칼데안 순서, 양자리 0도 화성부터 | — |
| 엑절테이션 도수 | 서양 전통 (태양 양자리 19도) | 베딕 값(10도)과 다르다 — 섞지 말 것 |
| 조합 궤 | 카지미 17분 · 조합 8도30분 · 태양광 아래 15도 | 베딕 조합 궤(행성마다 다름)와 다른 표 |
| 섹트 판정 | 태양이 7~12하우스면 낮 | 경계에 도수 여유를 주는 방식 |
| 로트 서브스턴스 | **아랍 전통(알비루니)** — ASC + 2H커스프 − 2H주인 | 헬레니즘 로트가 아님을 표시 |
| ZR 기간표 | 발렌스 (한 바퀴 211년) | — |
| ZR 단위 | 1단계 해, 2단계 달. 1년 = 365.2425일 | 360일 년을 쓰는 구현 |
| ZR 끈 풀림 | 열두 자리를 다 돌면 출발 자리의 **맞은편**으로 | — |
| 사주 재고 | 목고=未 화고=戌 금고=丑 수고=辰. 토는 두지 않음 | — |

## 3. 가장 중요한 설계 — 복권으로 뭉개지 않기

### ① "큰돈"을 곧바로 "복권"으로 옮기지 않는다

비정기 재물 신호가 잡히면 **출처 후보를 먼저 나눈다.**

```
직업(성과급·보상) · 사업(계약·매출) · 투자(주식·부동산)
· 제도(지원금·보험금) · 창작(상금·저작권) · 관계(배우자·상속)
· 순수횡재(복권·추첨)
```

순수횡재는 **5하우스(위험을 건 돈) 계열이 실제로 켜졌을 때만** 후보에 올린다.
켜지지 않으면 목록에서 아예 빠진다. 실제 검증 결과 한 명반에서 7개 후보 중
**6순위**로 나왔다 — 그게 정상이다.

### ② 버는 것 · 모으는 것 · 횡재하는 것을 따로 본다

포춘이 강하다고 로또형이 아니다. **포춘이 놓인 하우스가 경로를 가른다.**

| 포춘 하우스 | 현실화되는 모양 |
|---|---|
| 2 · 6 · 10 | 노동형 — 내 소득, 매일의 노동, 직업적 성과 |
| 3 · 9 | 전문성형 — 정보·기술·콘텐츠, 배움·외국 |
| 11 | 사업형 — 이익·후원·집단 |
| 4 · 12 | 투자형 — 집과 부동산, 드러나지 않는 자리 |
| 7 · 8 | 관계형 — 계약·파트너십, 남의 돈·상속 |
| **5** | **횡재형 — 투기·창작·위험을 건 쪽** |

### ③ 점수를 확률처럼 내보내지 않는다

경로 점수는 경로끼리 견주기 위한 내부값이다. 바깥으로는 **순위와 지지 체계
수**만 나간다. 여러 경로가 비슷하면 억지로 하나를 고르지 않고 "혼합형"이라고
말한다.

### ④ 시기는 여러 기법이 겹칠 때만

해마다 프로펙션·솔라 아크·재고충·세운 재성·세운 합을 센다. **기법이 둘 이상
겹치는 해만** 비정기 재물 시기 후보로 올린다. 하나만 걸린 해는 뽑지 않는다.

## 4. 금지 표현 (프롬프트에 못박음)

- "올해 로또 1등 된다"
- "이 날짜에 복권을 사면 된다"
- "이 번호가 당첨번호다"
- "횡재운이 있으니 복권 구입액을 늘려라"

대신 교차 신호가 충분하면:

> "평소보다 비정기 재물·투기·추첨 관련 영역이 강하게 활성화되는 기간이다."

**단언의 대상은 "재물 이벤트의 성격"이지 무작위 복권 결과가 아니다.**

> "너는 평생 예상하지 못한 목돈이 한두 차례 들어오는 구조가 있다.
>  다만 그 돈의 출처는 복권보다 계약·매출 쪽이 훨씬 두텁다."

---

## 5. 평생 재물 곡선

20·30·40·50·60대로 나눠 각 십 년의 중심을 말한다. 사주 대운(십신) · 베딕
마하다샤 · ZR 1단계(스피릿·포춘)를 같은 나이 축에 놓고 겹치는 것을 본다.
ZR 정점 구간에 걸린 십 년은 표시한다.

## 6. 질문별 계산 (`hires/router.js`)

무거운 계산이라 필요할 때만 켠다.

| 플래그 | 켜지는 조건 | 돌리는 것 |
|---|---|---|
| `needsWealth` | 재물 분야이거나 횡재 낱말 | 고전 차트 + 경로 합산 |
| `needsWindfall` | 횡재·로또·복권·목돈·큰돈·상금·상속 등 | + 연도별 겹침 + 출처 후보 |
| `needsLifetime` | 평생·인생·노후·말년 | + 십 년 곡선 + ZR |

재물과 무관한 질문(예: "2027년에 이직할까요?")에는 재물 구획을 싣지 않는다.
테스트가 이를 검사한다.

## 7. 테스트

`tests/unse/wealth.test.mjs` — 25개 (전체 128개)

- **고전 표** — 도미사일/엑절테이션/디트리먼트/폴, 도로테우스 트리플리시티가
  낮·밤에 갈리는가, 이집트 텀, 칼데안 페이스, 카지미/조합/태양광 아래가
  배타적이고 궤가 맞는가
- **로트** — 낮·밤 공식이 실제로 뒤집히는가(포춘↔스피릿), 주인의 상태까지
  돌려주는가, 시각 미상이면 만들지 않는가
- **ZR** — 기간표·한 바퀴 211년, 1단계가 순서대로 도는가, 2단계 합 = 부모
  구간, 끈 풀림이 맞은편으로 가는가, 정점 = 앵귤러
- **경로 분리** — 돈이 갈라지는가, 순위가 실제로 갈리는가, 모든 근거에
  체계·자리가 남는가, 재고는 창고 지지가 있을 때만
- **복권** — 출처 후보가 둘 이상인가, 5하우스가 안 켜지면 순수횡재를 후보에서
  빼는가, 순수횡재가 1순위면 다른 후보가 아예 없는 경우뿐인가
- **시기** — 기법이 둘 이상 겹친 해만 뽑는가
- **라우팅** — 횡재 질문이 재물을 켜는가, 무관한 질문에 재물 구획이 안 붙는가

## 8. 건드리지 않은 것

기존 계산식·기존 모듈의 동작은 그대로다. `router.js` 에 플래그 셋과 낱말
목록을 더하고, `context.js` 에 구획을 더한 것뿐이다.
