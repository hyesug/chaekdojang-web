# 시기 해석 감사표 — 15체계 × 분야

| 표시 | 뜻 |
|---|---|
| `direct` | 그 분야를 보는 **전용 시기 자리**가 있다 (궁·하우스·다샤 주인) |
| `indirect` | 시기 눈금은 있으나 분야 전용 자리는 없다 — 전체 기운에서 나눈다 |
| `/해` | 해 단위로만 바뀐다. 달을 가르지 못한다 |
| `—` | 시기 해상도가 없다 |

## 분야별 시간 해상도

| 분야 | 해상도 | 왜 |
|---|---|---|
| 기질 | year | 기질은 시기로 잘 안 움직인다 |
| 직업 | quarter | 이직·직무변경은 분기로 움직인다 |
| 관계 | month | 달 단위로 변한다 |
| 결혼 | halfyear | 결혼은 반년 단위로 준비된다 |
| 자녀 | halfyear | 임신·출산은 반년 창 |
| 학업 | month | 시험은 달 단위 |
| 재물 | month | 수입·지출은 달 단위 |
| 주거 | quarter | 계약·이사는 분기 |
| 이동 | quarter | 이동은 분기 |
| 건강 | month | 몸은 달 단위 |
| 큰 전환 | quarter | 큰 전환은 분기~해 |
| 시기 | year | 해 단위 |
