# 17체계 재구현 — 3단계 재검증 결과

2026-10-09. 기준은 `rebuild-criteria.md`(사전 등록)를 그대로 썼다. 재구현 내용은 `rebuild-audit.md` 2단계.
재현: `node scripts/audit-casebook.mjs` · `node scripts/validate-events.mjs` (사례 파일은 개인정보라 저장소 밖).

## 해석

- **"어떤 사람인가"(직업 성향·배우자 나이차)는 사례에서 기준선을 넘었다.** 단 나이차는 1명 차이라 약하다.
- **"언제"(결혼·출산 해)는 원전 규칙대로 다시 만든 뒤에도 명반을 안 보고 나이로 찍는 것보다 못했다.**
  결혼 안 한 4명에게는 모두 "이미 결혼했어야 할 해"를 짚었다.
- 조합을 사례로 골라도(한 명 빼기) 나아지지 않았다 — 고른 조합이 매번 바뀐다.

## 아직 남은 구현 한계 (결론을 바꿀 수 있는 것)

- 자미두수 판에 녹존·천마·괴월·육살이 아직 없다 (혼인 판단에 쓴 홍란·천희·함지·천요는 규칙 층에서 계산).
- 홍국기문·육임·태을신수·숙요·토정비결·마하보테는 혼인·출산 연도를 고르는 원전 규칙을 확인하지 못해 말하지 않는다.
- 사주 용신은 혼인의 길흉을 가르는 것이라 연도 규칙에 넣지 않았다.

## 리포트에 주는 뜻

- 합격 분야(직업 범주·나이차)는 단정해도 된다.
- 불합격 분야(결혼·출산 해)는 리포트에서 **해를 단정하지 않는다.** "검증되지 않았다"고 밝히거나 말하지 않는다.
- 판정 불가 분야는 "검증 중"으로 낸다.
