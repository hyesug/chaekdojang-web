# 17체계 구현 감사 (1단계)

2026-10-09. 체계마다 **원전 계산 vs 이 엔진의 계산**을 대조했다. 원국(태어난 판) 계산과
시기(언제) 계산을 따로 본다. 기준은 `rebuild-criteria.md` 의 사전 등록 기준이다.

## 가장 큰 구조 문제 — 모든 체계 공통

시기 엔진(`semantic/timing/adapters.js`)은 체계마다 분야별 **활성도**(그 자리가 얼마나 건드려졌나)를
낸다. 합과 충, 길과 흉을 한데 모은 "시끄러움"이다. 결혼한 해와 헤어진 해가 같은 점수를 받는다.

원전은 그렇게 보지 않는다. 결혼·출산·이직 같은 **사건마다 정해진 판단 규칙**이 따로 있다
(예: 여명은 관성이 세운에 들고 배우자궁이 합되는 해). → **재구현 0순위: 사건별 원전 규칙 층.**

## 체계별

### 핵심 넷 (명반을 세우는 체계)

| 체계 | 원국 계산 | 시기 계산의 원전과 다른 점 |
|---|---|---|
| 사주 | 골든 테스트 있음. 절기·대운수 정상 | ① 결혼 자리를 **성별 없이** 재성+관성 둘 다 봄 — 사례 3건을 보고 정한 것(원전 위반·사례 맞추기). 원전: 여명 관성·남명 재성 ② 용신·희기신을 시기에 안 씀 — 같은 관성이 와도 희신이면 혼인, 기신이면 파혼으로 갈리는 것을 구분 못 함 ③ 합과 충을 한 점수로 섞음 ④ 신살(홍란·천희·도화·역마) 없음 ⑤ 대운은 "바뀌는 해"만 봄 — 대운 십성·대운과 원국의 합충을 안 봄 |
| 자미두수 | 주성 14 + 보좌 4(좌보·우필·문창·문곡)만 배치 | ① **녹존·천마·천괴·천월, 육살(경양·타라·화성·영성·지공·지겁), 도화성(홍란·천희·함지·천요)이 아예 없음** — 혼인 시기를 보는 핵심 별이 판에 없다 ② 별의 밝기(묘왕리함) 미계산 ③ 시기: 대한·유년 사화 겹침만 봄. 원전: 유년 명궁·부처궁에 홍란·천희·화록이 드는 해, 대한 부처궁 |
| 점성술 (현대·고전) | 플라시더스 하우스, 천체 정확도 테스트 있음 | ① 트랜싯을 **하우스 커스프**에만 대 봄 — 원전은 배우자 표성(여: 태양·화성, 남: 달·금성), 금성, 7궁 주인 **행성 자체**에 대는 것을 먼저 본다 ② 2차 진행(진행 금성·진행 태양) 없음(진행 달만) ③ 목성 회귀·토성 회귀 같은 주기 미사용 |
| 베딕 | 라히리 아야남샤, 빔쇼타리 다샤 | ① 다샤 주인이 7궁 주인인가만 봄 — 원전은 금성·다라카라카·7궁주·7궁 거주 행성 다샤를 **결혼 다샤**로 따로 친다 ② **더블 트랜짓(목성·토성이 함께 7궁·7궁주를 볼 때)** 없음 — 베딕 결혼 시기의 대표 규칙 ③ D9 라그나·D9 7궁 다샤 미사용 |

## 재구현 순서 (2단계)

**사례 결과를 보지 않고** 아래만 원전대로 만든다. 결과는 3단계에서 한 번에 잰다.

1. **사건 규칙 층 신설** — 체계마다 결혼·출산 판단 규칙을 원전대로 (성별 구분 포함)
2. **사주** — 성별 배우자성, 용신·희기신, 합/충 분리, 홍란·천희·도화, 대운 십성·합충
3. **자미두수** — 녹존·천마·괴월·육살·홍란·천희·함지·천요 배치, 유년 부처궁 규칙
4. **점성술** — 배우자 표성·금성·7궁주 행성 트랜싯, 진행 금성·태양
5. **베딕** — 결혼 다샤 판정, 목성·토성 더블 트랜짓
6. **무작위·비개인 시기 제거·교체** — 타로(연간 카드), 숙요(구요성), 홍국(연·월국), 태국(마하탁사),
   마하보테(나이 주기), 육임(연·월 과전). 원전 방식을 구현할 수 없는 것(태을신수·토정비결 혼인)은
   **"이 체계는 결혼 시기를 말하지 않는다"로 빼고** 그 이유를 적는다.
