# 매주 재탐색 체계 조합 규칙 — 사전 등록 절차 (2026-10-15)

사용자 의도: 추첨 연월일시분으로 각 체계가 낸 후보 번호를 서로 다른 체계끼리 조합해 당첨번호를 내는 규칙을 찾고, 새 회차가 나올 때마다 처음부터 직전 회차까지 다시 찾아 가장 좋은 조합을 쓴다. 결과를 보기 전에 아래를 고정한다.

## 1. 후보 슬롯(최신 엔진)

- 기존 15체계 슬롯 33개(최신 엔진 값) + 고전점성술 4개(서울, 추첨 순간, `public/unse/src/hires/classical.js`):
  - `classical.c1_lot_fortune` 포르투나 로트 황경(360 → 1–45)
  - `classical.c2_lot_spirit` 스피릿 로트 황경(360 → 1–45)
  - `classical.c3_lot_substance` 서브스턴스(재물) 로트 황경(360 → 1–45)
  - `classical.c4_second_lord` 2하우스 주인(전통 7행성 순번, 7 → 1–45)
- 1–1245회 값이 완전히 같은 슬롯은 앞의 것 하나만 남긴다(당첨번호를 쓰지 않는 정리).

## 2. 조합식

- 단일 a, 두 슬롯 a+b · a−b · b−a · |a−b|, 세 슬롯 a+b+c · a+b−c · a−b+c · b+c−a. 값은 wrap45.
- 한 식 안의 슬롯은 서로 다른 체계여야 한다(체계 간 조합).

## 3. 규칙(매 회차 재탐색, 학습은 그 회차 이전만)

- C1 누적 재탐색 조합: 1회~직전 회차 전체에서 식마다 "식 번호가 당첨 6개에 든 비율"을 축소 추정(사전 6/45, 강도 200) → 높은 식부터 이번 회차 번호를 하나씩 담되 이미 담은 번호면 다음 식 → 6개. 동률은 식 목록 순서.
- C2 최근 300회 재탐색 조합: C1과 같고, 최근 300회만 본다(체계 궁합이 바뀐다고 가정).
- SYS-L-classical 고전점성술 단독: 다른 체계 단독 규칙과 같은 방식(슬롯 + 이웃 채움).
- 표본 외 기록은 101회(C2 는 301회)부터. 매 회차 고른 6개 식을 함께 기록한다.

## 4. 평가·편입

- 기존 재검증과 같은 지표: 개발 601–1100, 최종 1101–1245 평균 적중, 정확 초기하 p, 3+ 비율.
- 판정과 무관하게 순위표 후보에 넣는다(순위표는 성적 기록 도구). 기준선을 다시 만들고, 이미 저장된 1246회 순위표는 바꾸지 않는다.
